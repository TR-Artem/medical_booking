# Smoke-проверки

Автоматические тесты проекта находятся в `apps/accounts/tests` и `apps/appointments/tests`
(37 тестов Django). Запуск: `make test`.

Быстрая smoke-проверка развёрнутого стенда:

```bash
make api-test     # коды ответов основных маршрутов
make quality-check # тесты + маршруты + логи
```

Ожидаемый результат: публичные страницы 200, защищённые без входа 302,
несуществующий адрес 404, тесты 37/37.
