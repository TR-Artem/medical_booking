# RISK_REGISTER.md

> Репозиторий проекта: https://github.com/TR-Artem/medical_booking

| ID | Риск | Причина / признак | Вероятность | Влияние | Мера снижения |
|---|---|---|---|---|---|
| R-01 | Потеря данных при сбое | PostgreSQL в одном контейнере, регулярных копий нет | Средняя | Высокое | `pg_dump` по расписанию, проверка restore (этап 5) |
| R-02 | Утечка секретов | `.env.production` с паролями и `SECRET_KEY` лежит на рабочей машине | Средняя | Высокое | `.gitignore`, `.env.example` без секретов, ротация ключей, secret-скан |
| R-03 | Перехват трафика | Демо-стенд работает по HTTP, TLS не настроен | Средняя | Высокое | HTTPS через reverse-proxy и сертификат |
| R-04 | Подбор пароля | Нет ограничения попыток входа | Средняя | Среднее | Rate limiting, блокировка после N попыток, капча |
| R-05 | Отказ после перезапуска | Nginx кеширует IP `web`, сервисы зависят от порядка запуска | Средняя | Среднее | `restart: unless-stopped`, healthcheck, `restart nginx` в деплое |
| R-06 | Устаревшие зависимости | Версии закреплены, обновления вручную | Средняя | Среднее | `pip-audit`, обновление раз в квартал, CI-проверка (этап 6) |
| R-07 | Нет мониторинга | Логи только локально, алертов нет | Высокая | Среднее | Централизованные логи, healthcheck-эндпоинт, алерты |
| R-08 | Ошибки прав доступа | Закрытые разделы отдают 302 вместо 403 | Низкая | Среднее | Явные 403, тесты на роли |
| R-09 | Потеря демо-данных | `docker compose down -v` удаляет том | Низкая | Низкое | Отдельные имена проектов dev/prod, документация по backup |
| R-10 | Медленная страница при росте данных | Нет индексов под выборки расписания | Низкая | Среднее | Профилирование, индексы, пагинация |

## Связь с проверками

- R-05 подтверждён инцидентом 502 при пересоздании `web` (BUG-09), мера уже внедрена.
- R-08 подтверждён проверкой через Django test client (пациент → 302 на главную).
- R-02 проверяется этапом 5: `.gitignore`, поиск секретов, `pip-audit`.
