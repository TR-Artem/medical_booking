## Ограничения замера

- Замеры сделаны на локальной машине, без сети и внешней нагрузки.
- Нагрузочное тестирование (k6/JMeter) не проводилось: проект не имеет API и рассчитан на малую клинику. Для production рекомендуется отдельный нагрузочный сценарий.
