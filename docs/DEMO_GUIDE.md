# DEMO_GUIDE.md

> Репозиторий проекта: https://github.com/TR-Artem/medical_booking

## Подготовка стенда

```bash
make deploy     # production локально, http://localhost
make seed       # пользователи, врачи, расписание, записи
```

Для dev-стенда: `make run` и `make seed-dev`, адрес http://localhost:8080.

## Демо-доступы

| Роль | Логин | Пароль |
|---|---|---|
| Администратор клиники | `admin@test.ru` | `Test1234!` |
| Врач-кардиолог | `doctor@test.ru` | `Test1234!` |
| Врачи других специальностей | `doctor2@test.ru` … `doctor5@test.ru` | `Test1234!` |
| Пациент | `patient@test.ru` | `Test1234!` |

Логин совпадает с e-mail, вводится целиком.

## Сценарий показа (7–10 минут)

1. **Главная** — http://localhost/. Показать специальности, врачей, кнопки записи.
2. **Врачи** — /appointments/doctors/. Фильтр по специальности, 5 врачей.
3. **Запись** — войти пациентом `patient@test.ru`, открыть карточку врача, выбрать слот.
   - Свободные слоты видны на 7 дней.
   - Обеденный перерыв и занятые слоты недоступны.
   - После бронирования запись появляется в «Мои записи».
4. **Мои записи** — /appointments/my/. Показать 3 демо-записи и отмену.
5. **Кабинет врача** — выйти и войти `doctor@test.ru`.
   - Запись на сегодня, жалоба пациента, кнопки «Явился» / «Неявка».
6. **Админ-панель** — войти `admin@test.ru`.
   - Статистика: 1 запись сегодня, 5 врачей, 6 кабинетов.
   - Расписание: 35 записей на 7 дней, слоты и кабинеты.
   - Кабинеты: 6 кабинетов, деактивация.
7. **Django admin** — /django-admin/ под `admin@test.ru` (суперпользователь).

## Что считается успешной проверкой

- Все страницы открываются без 500.
- Вход работает под всеми четырьмя ролями.
- На главной и в списке врачей — 5 врачей без дублей.
- Слоты есть на каждый из 7 дней; занятые и обеденные не показываются.
- Запись создаётся, отображается у пациента и врача, отменяется.
- `make check` — ruff, black и 50 тестов проходят.
- `make check-deploy` — сервисы `running`, HTTP 200, в логах нет traceback.

## Известные ограничения

- Письма требуют SMTP из `.env` / `.env.production`; в демо они не доставляются, ошибок нет.
- Одна клиника, без филиалов и мультитенантности.
- Демо-пароль публичный — только для стенда.
- VPS-развёртывание требует домена и доступов; локальный стенд работает по HTTP.
