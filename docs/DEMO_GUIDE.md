# DEMO_GUIDE.md

> Репозиторий проекта: https://github.com/TR-Artem/medical_booking

## Как быстро проверить проект

1. Запустить стенд: `make deploy` (или `scripts\deploy.bat`).
2. Открыть http://localhost.
3. Проверить основной сценарий:
   - главная страница открывается, видны кнопки «Найти врача» и «Зарегистрироваться»;
   - страница входа: http://localhost/accounts/login/;
   - вход под администратором: после входа появляется сообщение «Добро пожаловать, <логин>!».

## Тестовые данные

Учётные записи создаются командами, а не берутся из README:

```bash
make migrate
docker compose -f docker-compose.prod.yml --env-file .env.production exec web python manage.py createsuperuser
```

Логин и пароль задаются при создании (для демо-стенда в этом проекте: логин `admin`, пароль задан в `.env` / при создании). Пароли не публикуются в репозитории.

## Что считается успешной проверкой

- Приложение открылось по http://localhost.
- Основной сценарий выполнен: вход администратором прошёл.
- Критических ошибок нет: `make check-deploy` показывает все сервисы `running`, HTTP 200, в логах нет traceback.
- Тесты проходят: `make check` (ruff, black, 37 тестов).

## Известные ограничения демо-стенда

- Стенд работает только на локальной машине, внешнего доступа нет.
- Письма отправляются через SMTP из `.env.production`; без сервера SMTP письма не уходят, но сайт работает.
- HTTPS не настроен (только HTTP на порту 80).
