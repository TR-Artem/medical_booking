# Проблема: закрытые разделы отдают 302 вместо 403

> Репозиторий проекта: https://github.com/TR-Artem/medical_booking

## Описание

При попытке открыть раздел без прав пользователя переадресует на главную страницу (HTTP 302). Из-за этого непонятна причина отказа, а мониторинг и тесты не видят событие «доступ запрещён».

## Шаги воспроизведения

1. Войти пациентом: `patient` / `Demo1234!`.
2. Открыть `http://localhost/appointments/admin/dashboard/`.
3. Наблюдать редирект на `/`.

## Ожидаемый результат

HTTP 403 и страница «Доступ запрещён» с объяснением и кнопками возврата.

## Фактический результат

HTTP 302 на главную, причина видна только в flash-сообщении.

## Окружение

- ОС: macOS 15
- Python 3.12, Django 5.2.19
- Режим запуска: Docker Compose (production/demo)

## Доказательства

- Проверка через Django test client: `patient -> /appointments/admin/dashboard/ = 302 /`.
- Скриншот `05_roles_access_check.png` этапа 4.
- Код: `apps/appointments/views.py`, декораторы `admin_required`, `doctor_required`, `sysadmin_required`.
